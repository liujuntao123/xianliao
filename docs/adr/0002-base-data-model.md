# Base 数据建模：四张数据表 + 双向关联 + 中文表名字段名

Base 内建四张数据表：清单（名称）、任务（标题/已完成/截止日期/所属清单→关联清单表）、子任务（标题/已完成/所属任务→关联任务表）、笔记（标题/正文）。表名与字段名一律用中文——用户会直接在飞书里打开这个 Base，中文可读性优先；代码侧用常量映射隔离。否决的替代方案：清单做成任务表上的单选字段（重命名清单需改写全部记录、清单无法独立管理）；子任务编码进任务记录的文本字段（飞书 UI 完全不可读）。

## Consequences

- 子任务是独立记录，勾选子任务 = 一次记录更新 API 调用。
- 关联字段写入的是对方表的 record_id 数组，读取任务列表需要联表（单用户数据量下一次全量拉取 + 内存组装即可）。
